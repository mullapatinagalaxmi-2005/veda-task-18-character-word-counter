# Veda Technology – Task 18: Character and Word Counter

## 📌 Project Overview

The Character and Word Counter is a responsive web application developed using HTML, CSS, and JavaScript. It counts characters, words, and sentences instantly as the user types text into the text area.

## ✨ Features

- Live character count, including spaces
- Character count excluding whitespace
- Live word count
- Sentence count
- Clear Text button
- Handles multiple spaces and line breaks
- Responsive design for desktop and mobile devices
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5 – Webpage structure
- CSS3 – Styling and responsive layout
- JavaScript – Text processing and live counter updates

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
