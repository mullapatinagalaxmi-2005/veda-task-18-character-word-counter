
# Veda Technology – Task 18: Character and Word Counter

## Project Overview
A responsive web application that counts characters, characters without spaces, words, and sentences as the user types.

## Features
- Live character count
- Character count without whitespace
- Live word count
- Sentence count
- Clear text button
- Responsive design
- Handles multiple spaces and line breaks

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if necessary.
4. Right-click index.html.
5. Select Open with Live Server.

## Learning Outcomes
- Handling textarea input events
- Using JavaScript string methods and regular expressions
- Updating the DOM dynamically
- Counting words while handling extra whitespace
- Creating responsive layouts
